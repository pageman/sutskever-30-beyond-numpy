# Verification Status Vocabulary

Use these terms consistently in `NOTES.md` and `verification.yaml`.

- `substantive`: the layer carries real explanatory or verification value for the paper
- `partial`: the layer does meaningful work but only covers a limited slice of the paper
- `minimal but meaningful`: the layer is intentionally small but still carries real signal
- `minimal`: present and real, but only at a thin baseline level
- `present`: included for completeness with low direct value
- `ceremonial`: structurally present but not carrying real verification or explanatory weight
